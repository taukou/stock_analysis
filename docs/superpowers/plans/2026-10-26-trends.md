**Interfaces:**
- Produces:
  - `PERIODS: tuple[int, ...] = (1, 5, 20)`
  - `trading_dates(rows: list[dict]) -> list[str]`：rows 是 `daily_quotes` 列（`trade_date` ISO 字串、`market`、`close`）；回傳 `market` 為 `上市` 或 `上櫃` 且 `close` 非 null 的不重複日期，**新到舊**。
  - `period_return(n: int, dates: list[str], closes: dict[str, float | None], latest_change_pct: float | None, ex_events: list[dict]) -> float | None`
    - `n == 1`：回傳 `latest_change_pct`（呼叫端給 `dates[0]` 那天的 `change_pct`）。
    - `n > 1`：`len(dates) <= n` → `None`；`last = dates[0]`、`base = dates[n]`；`closes[last]` 或 `closes[base]` 缺／≤0 → `None`；`factor = Π(prev_close / ref_price)`，取 `base < ex_date <= last` 且兩值皆 > 0 的事件；回傳 `round((closes[last] / closes[base] * factor - 1) * 100, 2)`。
  - `ex_kind_in_period(n: int, dates: list[str], ex_events: list[dict]) -> str | None`：`len(dates) <= n` → `None`；否則視窗 `(dates[n], dates[0]]`；回傳視窗內最新一筆事件的 `kind`（`除息`／`除權`／`除權息`），沒有則 `None`。
  - `node_average(values: list[float | None]) -> tuple[float | None, int]`：排除 `None` 的等權平均，`round(…, 2)`，與納入家數；全缺 → `(None, 0)`。

### Task 2: 訊號規則與資料新鮮度（`signals.py`、`freshness.py`）

**Files:**
- Create: `signals.py`, `freshness.py`
- Test: `tests/test_signals.py`, `tests/test_freshness.py`

**Interfaces:**
- Produces（`signals.py`）：訊號一律是 `{"code": str, "label": str, "detail": str}`。
  - `month_index(data_month: str) -> int`：`"115/09"` → `115 * 12 + 9`。
  - `trust_streak(dates: list[str], trust_by_date: dict[str, int | None], min_days: int = 5) -> dict | None`：從 `dates[0]` 往回數 `trust_net > 0` 的連續日數（缺日或 null 即中斷）；`len(dates) < min_days` 或連續數 < `min_days` → `None`；否則 code `trust_streak`、label `投信連買 {k} 日`、detail `近 {k} 個交易日投信皆買超`。
  - `yoy_turn_positive(revenue: list[dict]) -> dict | None`：revenue 列含 `data_month`、`yoy_pct`；取最新兩個月，須相鄰（`month_index` 差 1）且皆非 null；最新 > 0 且前月 ≤ 0 → code `yoy_turn`、label `營收年增轉正`、detail `{前月} {p:+.2f}% → {本月} {c:+.2f}%`。
  - `revenue_12m_high(revenue: list[dict]) -> dict | None`：取最新月往回 12 個連續月份（`month_index` 連續），12 筆 `revenue` 皆非 null，且最新 > 前 11 個月最大值 → code `revenue_high`、label `營收創 12 個月新高`、detail `{本月} 營收 {revenue:,} 千元`。
  - `volume_spike(dates: list[str], volume_by_date: dict[str, int | None], mult: float = 2.0, window: int = 20) -> dict | None`：需 `len(dates) >= window + 1`；`dates[0]` 量與 `dates[1:window+1]` 的 20 個量都非 null；今日量 ≥ 均量 × `mult` → code `volume_spike`、label `爆量`、detail `成交量 {今日:,} 股，為 20 日均量 {倍數:.1f} 倍`。
  - `company_signals(dates, trust_by_date, revenue, volume_by_date) -> list[dict]`：依序呼叫四條規則，收集非 None。
- Produces（`freshness.py`）：
  - `latest_runs(rows: list[dict]) -> dict[str, dict]`：rows 為 `sync_runs`（新到舊），每個 `dataset` 取第一筆。
  - `weekday_lag(last_date: str, now: datetime) -> int`：`now.hour < 15` 時以前一個工作日為「應有日」，否則以今天（若今天是週末則往前到週五）；回傳 `last_date` 之後到應有日（含）之間的週一至週五天數。
  - `freshness(rows: list[dict], now: datetime) -> dict`：回傳 `{"level": "ok"|"stale"|"failed", "message": str, "datasets": [{"dataset","last_date","status","finished_at"}]}`；任一 dataset 最新一次 `status == "failed"` → `failed`（message 列出失敗的 dataset）；否則 `quotes` 或 `institutional` 的 `weekday_lag > 1` → `stale`；否則 `ok`。`message` 一律以 `資料更新至 {quotes 的 last_date}` 開頭（quotes 缺 → `資料更新至 —`）。datasets 依 `quotes, emerging, institutional, ex_rights, revenue` 排序。

def test_build_snapshot_returns_and_emerging():
    days = ["2026-09-22", "2026-09-19", "2026-09-18", "2026-09-17", "2026-09-16", "2026-09-15"]
    quotes = [q("2330", d, 100.0 + i, 0.5) for i, d in enumerate(reversed(days))]
    quotes.append(q("6999", "2026-09-22", 50.0, 1.2, market="興櫃"))
    s = build_snapshot(quotes, [], [], [])
    assert s["dates"][0] == "2026-09-22" and s["latest_date"] == "2026-09-22"
    assert s["returns"]["2330"][1] == 0.5
    assert s["returns"]["2330"][5] == 5.0      # 105 / 100 − 1
    assert s["returns"]["6999"] == {1: 1.2, 5: None, 20: None}

def test_cache_ttl_and_stale_on_error():
    t = [0.0]; calls = []
    def loader():
        calls.append(1)
        if len(calls) == 2: raise RuntimeError("down")
        return {"n": len(calls)}
    c = SnapshotCache(loader, ttl=600, clock=lambda: t[0])
    assert c.get() == {"n": 1}
    t[0] = 100; assert c.get() == {"n": 1} and len(calls) == 1
    t[0] = 700; assert c.get() == {"n": 1}            # loader 失敗 → 回舊值
    t[0] = 1400; assert c.get() == {"n": 3}

def test_cache_raises_without_stale():
    c = SnapshotCache(lambda: (_ for _ in ()).throw(RuntimeError("down")), clock=lambda: 0.0)
    with pytest.raises(RuntimeError):
        c.get()
